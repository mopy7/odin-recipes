# Odin Recipes 🍽️

A simple HTML project built as part of **The Odin Project** curriculum.  
This project demonstrates basic HTML structure, links, images, and lists by creating a small recipe website.

---

## 📌 Project Overview

**Odin Recipes** is a static website that contains a collection of recipes.  
Each recipe has its own page with ingredients and step-by-step cooking instructions.

This project focuses on:
- Writing clean HTML
- Structuring a basic multi-page website
- Using links and images correctly

---

## 🛠️ Technologies Used

- HTML5  
- Git & GitHub  

---

## 📂 Project Structure

```bash

odin-recipes/
│
├── index.html
├── recipes/
│ ├── recipe1.html
│ ├── recipe2.html
│ └── recipe3.html
└── images/

```

---

## ✨ Features

- Home page with links to individual recipes
- Separate pages for each recipe
- Ordered and unordered lists for ingredients and steps
- Images added to enhance visual understanding
